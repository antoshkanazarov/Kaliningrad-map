# Kaliningrad-map
An interactive, mobile-friendly map of 10 must-visit places in Kaliningrad and the surrounding region, with search, filters, and links to maps.

## Локальный запуск

Сайт статический: регистрация, серверная часть и база данных не нужны.
Для локальной проверки из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Страница находится в `index.html`, фотографии — в `assets/images`, стили — в
`assets/css`, скрипты — в `assets/js`. При публикации загружайте весь репозиторий,
включая `assets`; относительные пути подходят для GitHub Pages.

Leaflet и MapLibre хранятся локально; подложка OpenFreeMap требует подключения к интернету.
Фотографии карточек загружаются отложенно. Клавиша `/` переводит фокус в поиск,
`Escape` очищает запрос. Поиск учитывает название, описание и адрес; слова запроса
могут идти в любом порядке. Маршрут, посещения и размер текста сохраняются в localStorage этого браузера. Сайт не создаёт cookies, не требует регистрации и не отправляет этот прогресс на сервер. Прогресс сохраняется после закрытия браузера, пока пользователь не очистит данные сайта; между устройствами он автоматически не переносится.

## Границы области

`assets/js/region.js` содержит локальную геометрию Калининградской области
(geoBoundaries gbOpen RUS ADM1, ревизия `9469f09`; источник OpenStreetMap / Wambacher,
лицензия [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)).
[Исходные данные](https://github.com/wmgeolab/geoBoundaries/tree/9469f09/releaseData/gbOpen/RUS/ADM1).
Координаты округлены до шести знаков. Маска затемняет пространство за границами;
контур и маска не перехватывают нажатия на карту. При открытии показывается вся
область, при поиске — найденные места. Геометрия хранится локально, без запроса
к стороннему геосервису при каждом открытии карты.

## Пользовательские сценарии

На телефоне нижняя навигация открывает список, карту и личный маршрут.
В карточке места закреплены кнопки сохранения и перехода к карте. Добавление,
удаление и изменение порядка остановок можно отменить из уведомления.
Отмена относится только к последнему изменению и не хранится после перезагрузки;
при обновлении маршрута в другой вкладке устаревшая отмена сбрасывается.

Активные фильтры видны отдельными кнопками и снимаются независимо друг от друга.
На узких экранах дополнительные фильтры собраны в раскрываемый блок. Уведомления
о невозможности сохранения объясняют, что данные останутся только до закрытия
страницы. Общие сценарии сохраняют управление с клавиатуры и возврат фокуса.

## Русские подписи карты

Подложка OpenFreeMap Liberty отображается через MapLibre GL JS 5.24.0 и адаптер
MapLibre GL Leaflet 0.1.3. Локальные копии MapLibre и их лицензии — в
`assets/vendor`. Leaflet, MapLibre и стили карты загружаются только при открытии карты. Управляет загрузкой
`assets/js/russian-map.js`. API-ключи и сборка не нужны.

Для географических названий стиль предпочитает поле OpenStreetMap `name:ru`.
Если перевода нет, используется местное `name`; номера дорог сохраняются.
Векторные данные, шрифты и стиль загружаются с `tiles.openfreemap.org`.
Браузеру нужен WebGL. При ошибке загрузки остаются список и метки мест,
появляется кнопка повторной попытки. Атрибуция OpenFreeMap, OpenMapTiles и
OpenStreetMap сохраняется вместе с атрибуцией географических границ.

## Планирование и общие маршруты

«План на день» подбирает редакционные программы по времени посещения, интересам
и готовности к переездам. В личном маршруте показана сумма известных оценок;
дорога и ожидание в неё не входят. При недостаточных данных точный итог не
выдумывается. Кнопка «Поделиться маршрутом» создаёт ссылку вида
`?route=1,7,6#shared-trip`. Получатель видит предварительный список и явно
добавляет его к своему маршруту, с сохранением прежних остановок и возможностью
отмены. Некорректные ссылки не меняют личные данные.

Логика — в `assets/js/trip-tools.js`, оформление — в
`assets/css/trip-tools.css`. Продуктовое обоснование — в
[docs/product-direction.md](docs/product-direction.md).

Проверка ограничений подбора и оценок длительности без внешних зависимостей:

```sh
node --test tests/*.test.cjs
```

## Оформление интерфейса

`assets/css/apple-ui.css` задаёт светлые поверхности, системную типографику,
синие акценты и состояния кнопок. Окна мест сохраняют нативную семантику dialog,
управление клавиатурой и закреплённые действия. Плавное открытие отключается при
`prefers-reduced-motion`. Шрифты и дополнительные UI-библиотеки не загружаются.
