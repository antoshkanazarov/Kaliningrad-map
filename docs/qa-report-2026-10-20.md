# Финальная QA-проверка — 20 октября 2026

Проверена статическая версия сайта перед отправкой в GitHub. Среда: Chromium
в Linux, Playwright Core 1.61.1; автоматический аудит axe-core 4.11.0.

## Результаты

- Пройдены 6 Node.js-тестов: ограничения подбора программ, оценки времени,
  локальные ресурсы и якоря, уникальность ID, отложенная загрузка карты,
  отсутствие зависимостей от аккаунтов/API и записи cookies.
- Проверены ширины 320, 375, 768, 1280 и 1440 px,
  альбомный экран 844×390 и базовый шрифт до 200%. Горизонтального переполнения
  в проверенных сценариях нет. Действия карточки остаются доступны.
- Проверены все 16 карточек и все 63 остановки самостоятельных экскурсий.
- Пройдены поиск, очистка, независимые фильтры, пустая выдача, режим чтения,
  увеличение текста, Escape, возврат фокуса и уменьшенная анимация.
- Пройдены добавление/удаление/порядок остановок, отмена, готовые программы,
  подбор по ограничениям и предупреждения о времени.
- Пройдены общая ссылка, предварительный просмотр и объединение без перезаписи
  личного списка, неверная ссылка, отказ доступа к буферу обмена.
- Пройдены экспорт экскурсии и маршрута в самостоятельные HTML-файлы, подготовка
  обратной связи при недоступном буфере обмена, геолокация пяти ближайших мест
  и очистка результата.
- Прогресс маршрута, посещений и размера текста сохраняется после полного
  закрытия и повторного запуска Chromium с тем же профилем. В проверенном
  гостевом сценарии cookies не создавались и запросов к `/api/` не было.
- Русская карта проверена на компьютере и телефоне: реальные географические
  подписи, контур и затемнение, 10 меток, карточки, фильтрация и сброс. Проверены
  отказ сервиса и повторная попытка, а также сбой загрузки адаптера библиотеки.
- Без JavaScript доступны 10 основных, 6 дополнительных мест и тексты всех
  экскурсий. Ни отсутствующих локальных файлов, ни неверных якорей не найдено.
- axe-core после исправлений не обнаружил нарушений WCAG A/AA/2.1 AA в состояниях
  «страница», «открытая карточка», «чтение». Остались элементы, требующие ручной
  оценки; автоматический отчёт не является подтверждением полного соответствия.

## Исправления и оптимизация

1. Повышен контраст мелких подписей карточки и панели чтения.
2. Исправлена специфичность CSS заголовка подвала: его размер больше не
   переопределяется стилями обычного абзаца.
3. Подпись размера текста учитывает фактический базовый размер шрифта.
4. Leaflet JS и CSS загружаются только при открытии карты: из начальной загрузки
   исключены 162 976 байт исходных ресурсов. Это размер несжатых файлов,
   а не результат измерения передачи через CDN. MapLibre тоже остаётся отложенным.
5. Повторные попытки загрузки используют уже полученные библиотеки и стили;
   неуспешные запросы можно повторить. Ожидание загрузки библиотек ограничено.
6. Сохранён переход к конкретному месту при самом первом открытии карты,
   когда библиотека ещё загружается. Проверен масштаб и открытие нужной метки.

## Повторяемые проверки

Без сторонних зависимостей:

```sh
node --test tests/*.test.cjs
```

Для браузерного smoke-теста нужен Chromium. Сам сайт установки npm-пакетов
не требует. Инструмент можно установить отдельно от репозитория:

```sh
npm install --prefix /tmp/baltika-qa --cache /tmp/baltika-npm-cache \
  --no-package-lock playwright-core@1.61.1
```

Запустите статический сервер по инструкции README, затем в другом терминале:

```sh
NODE_PATH=/tmp/baltika-qa/node_modules node tests/browser-smoke.cjs
```

При необходимости задайте `BASE_URL` и `CHROMIUM_PATH`. Smoke-тест проверяет
гостевой сценарий и не обращается к картографическому провайдеру.

## Границы проверки

Физические iOS/Android, Safari, Firefox и скринридеры не проверялись.
Внешние расписания, билеты и актуальность сведений площадок не подтверждались.
Карта требует интернета и WebGL; при недоступности подложки остаются метки и
список мест. Проверка локальной версии не подтверждает публикацию GitHub Pages
или показатели скорости в реальной мобильной сети.
